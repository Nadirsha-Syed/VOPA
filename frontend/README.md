# VOPA Frontend Repository

Welcome to the **VOPA (Vowels of the People Association)** Frontend Application!

**Primary Message:** "Every Voice Learns. Every Child Belongs."

This frontend application unifies all experiences across the platform:
1. **Student Experience** (Reading, Speech Recognition, Results, Progress, Languages)
2. **Teacher Experience** (Class performance, Analytics, Students needing attention, Reading reviews)
3. **Admin Experience** (User management, Exercise management, Language settings, Platform metrics)
4. **Authentication** (Login, Register, Role-based route guards)

## Technology Stack
- **Framework:** React 19 + Vite 8
- **Styling:** Tailwind CSS + Custom Design System
- **Routing:** React Router DOM v7
- **Icons:** Lucide React
- **Charts:** Recharts
- **HTTP Client:** Axios

## Getting Started

```bash
cd frontend
npm install
npm run dev
```

Build for production:
```bash
npm run build
```
